Rocket Hub

HARDWARE FLUTTER ESP32-C3 JUGEND FORSCHT 2026

Rocket Hub is a comprehensive hardware and software ecosystem I developed for the Jugend Forscht 2026 competition. It bridges the gap between local IoT hardware and cloud AI.

Hardware Architecture

At the core of the system is a custom PCB built around the ESP32-C3 RISC-V microcontroller. The entire board was modeled and routed using KiCad, optimizing for a compact footprint while providing robust power delivery for external sensors and components.

Software & AI

The consumer-facing interface is a beautiful, cross-platform mobile app written in Flutter ("Rocket Hub Consumer"). Additionally, the hub integrates a dedicated AI backend ("Rocket Hub KI") which intelligently orchestrates connected devices, removing the need for manual scheduling.
