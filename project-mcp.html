MCP Server Ecosystem

AI AGENTS APIS INTEGRATION

I have built a suite of custom Model Context Protocol (MCP) servers that bridge the gap between autonomous AI agents and local desktop applications.

The Integrations

Safari MCP: Allows AI agents to actively control, browse, and extract DOM information from the Safari web browser.
Obsidian MCP: Exposes my local Obsidian vault to AI, enabling seamless read/write access to my knowledge graph.
Fusion 360 MCP: A highly experimental server that allows AI agents to interface directly with Autodesk Fusion 360, translating text commands into 3D CAD operations.

Impact

By exposing local software APIs to the Model Context Protocol, my computer essentially becomes a fully controllable environment for agentic coding and automation.
